# 🎓 Student Performance Prediction

A Python machine learning project that predicts student final marks using student data.

## 🎯 Objective

To predict student final marks using Machine Learning techniques.

## ✨ Features

- Read student data from CSV
- Analyze student data
- Train a Machine Learning model
- Predict final marks
- Show student performance category

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib
- Joblib

## 📁 Project Structure

```text
Student-Performance-Prediction/

├── dataset/
```

## ▶️ How to Run

### 1. Install the required libraries

```bash
pip install -r requirements.txt
```

### 2. Train the model

```bash
python src/train.py
```

### 3. Predict student performance

```bash
python src/predict.py
```

## 📊 Dataset

The project uses student information such as:

- Study Hours
- Attendance
- Assignment Score
- Previous Marks
- Final Marks

The dataset is used to train a machine learning model for predicting final marks.

## 🤖 Machine Learning Model

This project uses:

- Linear Regression
- Train-Test Split
- Scikit-learn

The trained model is saved as:

```text
models/student_model.pkl
```
